# Куда уходят заявки с формы

API endpoint: `POST /api/nda-request`. После успешной отправки сервер пытается отправить уведомление по двум каналам. Оба настраиваются через `.env`.

## Канал 1: Telegram-бот (рекомендую — мгновенно, бесплатно)

Заявка прилетает в Telegram через 1–2 секунды после нажатия «Получить оффер». Сообщение содержит имя, email, телефон + кликабельные ссылки `tel:` и `wa.me/<номер>` — можно сразу позвонить или написать в WhatsApp.

### Как настроить (5 минут)

1. **Создайте бота:**
   - В Telegram откройте чат с [@BotFather](https://t.me/BotFather)
   - Отправьте `/newbot`
   - Дайте имя (любое, например `Jazz Hotel Leads Bot`)
   - Дайте username (должен заканчиваться на `bot`, например `jazz_hotel_leads_bot`)
   - BotFather пришлёт **HTTP API token** вида `7891234567:ABC-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

2. **Откройте чат с ботом** (по ссылке которую дал BotFather), нажмите `Start` или отправьте любое сообщение — это активирует чат.

3. **Получите ваш chat ID:**
   - Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   - В ответе найдите `"chat":{"id":XXXXXXXX,...}` — это число и есть ваш `chat_id`
   - Если не видите своего сообщения — отправьте боту любое сообщение и обновите страницу

4. **Добавьте в `.env`:**
   ```
   TELEGRAM_BOT_TOKEN=7891234567:ABC-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TELEGRAM_CHAT_ID=123456789
   ```

5. **Перезапустите сервер.** Готово — следующая заявка прилетит в Telegram.

### Хотите получать в группу/канал, а не в личку?

- Создайте группу, добавьте туда бота
- Отправьте в группе любое сообщение
- Тот же `getUpdates` URL покажет `chat_id` группы (отрицательное число вида `-1001234567890`)
- Используйте этот `chat_id` в `.env`

## Канал 2: Email через Resend

Заявка приходит на `info@aurahomes.ge` (или другой email, заданный в `SELLER_EMAIL`). Заявителю автоматически отправляется письмо-подтверждение «свяжемся в течение 24 часов».

### Как настроить

1. Зарегистрируйтесь на [resend.com](https://resend.com) (бесплатно до 3000 писем/мес)
2. Добавьте домен `aurahomes.ge`, пройдите DNS-верификацию (SPF/DKIM записи)
3. Получите API key в Settings → API Keys
4. Добавьте в `.env`:
   ```
   RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxx
   SELLER_EMAIL=info@aurahomes.ge
   FROM_EMAIL=nda@aurahomes.ge
   ```

## Про WhatsApp

Программно слать сообщения **в** WhatsApp требует [WhatsApp Business Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api) от Meta — нужна верификация бизнеса, привязка телефона, утверждённые шаблоны сообщений. Для MVP это избыточно.

**Telegram-бот — практически такая же функциональность за 5 минут.** Если нужно именно WhatsApp — могу добавить интеграцию через сторонний сервис (Twilio, Wassenger, etc.), но это платно и требует отдельной настройки.

## Что если ни одного канала не настроено

Заявка всё равно сохраняется — сервер логирует её в stdout (видно в логах Vercel/Cloudflare). Так что заявки не теряются, но получать их «вживую» можно только через Telegram или email.

## Лог формат (если нужно для самостоятельной интеграции)

При наличии заявки сервер также мог бы:
- Записывать в Google Sheet (нужен service account)
- Слать в Notion DB (нужен Notion API token)
- Писать в свою БД (Postgres / Supabase)

Любой из этих каналов — добавляется в `src/pages/api/nda-request.ts` ~10 строками кода.
